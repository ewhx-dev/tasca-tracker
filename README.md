# Tasca

Un piccolo tracker delle spese, semplice e privato. Aggiungi entrate e uscite, tieni d'occhio il saldo del mese ed esporta i movimenti in CSV.

## Avvio

Apri `index.html` in un browser: non servono installazioni, server o dipendenze.

## Funzionalità

- Riepilogo mensile di saldo, entrate e uscite.
- Aggiunta di movimenti con descrizione, categoria, importo e data.
- Filtro per entrate e uscite; eliminazione dei movimenti.
- Esportazione di tutti i movimenti in formato CSV.
- Salvataggio locale nel browser tramite `localStorage`: i dati non vengono inviati a un server.
- Interfaccia responsive, in italiano.

## Dati e privacy

I movimenti restano nel browser e sul dispositivo in cui vengono inseriti. Cancellando i dati del sito dal browser, i movimenti salvati andranno persi. Il progetto non richiede account e non usa servizi backend.

## Tecnologie

HTML, CSS e JavaScript standard, senza framework o dipendenze.
